# 🎯 Objectives

- Understand basic Java syntax
- Practice input/output operations
- Learn arithmetic operations
- Explore control structures
- Improve logical thinking

# 🛠 How to Run the Programs

## Make sure Java is installed:

```tsx
java -version
```

## Compile any program:

```tsx
javac Q1hello.java
```

## Run the program:

```tsx
java Q1hello
```
> Replace Q1hello with the file name you want to run.
